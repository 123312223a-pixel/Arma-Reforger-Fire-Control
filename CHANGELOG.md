# История версий

## 3.6.0 — Windows Update Center
- Настольная версия Tauri 2 для Windows.
- Локальная резервная копия целей и орудий в AppLocalData.
- Интерфейс проверки подписанных обновлений.
- Ручная установка обновлений после подтверждения.
- Сохранено проверенное баллистическое ядро версии 3.5.
- M777 и M252: 6400 тыс./круг. 2Б14: 6000 тыс./круг.

Подписанный канал заработает после генерации ключей, настройки GitHub Secrets/Variables и первой подписанной сборки.

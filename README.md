# Arma Reforger Fire Control

**Arma Reforger Fire Control** — неофициальный офлайн-калькулятор артиллерии для Windows на базе **Tauri 2**.

> **Статус публикации:** репозиторий создан, исходный проект и первый установщик готовятся к загрузке. Пока здесь нет доступного для скачивания релиза.

## Возможности приложения

- Расчёты для M777, M252 и 2Б14 «Поднос».
- Угловые шкалы: M777/M252 — 6400 тысячных; 2Б14 — 6000.
- Тактическая карта, компас и несколько орудий.
- Именованные цели, группы, история и библиотека целей.
- Поправки по сторонам света, сравнение зарядов, таймер полёта и сохранённые огневые задачи.
- Локальное хранение данных, экспорт и импорт JSON.
- Поддержка подписанных обновлений после настройки публичного канала релизов.

После публикации первого установщика он появится в разделе **[Releases](https://github.com/123312223a-pixel/Arma-Reforger-Fire-Control/releases)**. До первого релиза скачивать пока нечего.

## Конфиденциальность

Сохранённые пользователем координаты, история, библиотека целей и настройки хранятся локально в приложении. Публикация исходников не загружает пользовательские сохранения в GitHub.

## Сборка из исходников

После загрузки проекта потребуется Windows 10/11, Node.js LTS, Rust и Microsoft C++ Build Tools. Для сборки Tauri используется WebView2. Пошаговая инструкция и автоматическая сборка появятся вместе с исходниками.

## Обновления

Обновления будут распространяться через GitHub Releases и проверяться криптографической подписью Tauri. Приватный ключ подписи **никогда не должен попадать в репозиторий**.

# Arma Reforger Fire Control

**Arma Reforger Fire Control** — бесплатное неофициальное Windows-приложение для расчётов артиллерии в Arma Reforger. Работает офлайн на базе Tauri 2 и сохраняет данные пользователя локально.

**[Скачать последнюю версию для Windows (Releases)](https://github.com/123312223a-pixel/Arma-Reforger-Fire-Control/releases/latest)** · **[Полное руководство](GUIDE_RU.md)** · **[История изменений](CHANGELOG.md)**

## Установка

1. Откройте **Releases → Latest** по ссылке выше.
2. Скачайте файл вида `Arma.Reforger.Fire.Control_<версия>_x64-setup.exe`.
3. Закройте старую версию Fire Control (если она запущена) и установите программу.
4. Запустите приложение через меню «Пуск» или ярлык Windows.

Для Windows 10/11 используется WebView2. При первой установке система может скачать нужный компонент. Внимание: цифровая подпись обновлений Tauri не равна сертификату издателя Windows; SmartScreen может показывать предупреждение для новых приложений.

## Возможности

- **Орудия:** M777, M252, 2Б14 «Поднос»; автоматическое различие шкал 6400/6000 тысячных.
- **Координаты и ручной ввод:** наведение, ветер, разница высот, заряды, время полёта, VT.
- **Поправки:** смещение цели по сторонам света с отменой шагов.
- **Тактическая карта:** сохранённые орудия и цели, именованные метки, группы, фильтры, история, компас.
- **Батарея:** расчёт по нескольким позициям и сравнение доступных зарядов/траекторий.
- **Огневые задачи и таймер:** сохранение комбинаций и ручной отсчёт времени полёта.
- **Архив:** история, профили, импорт/экспорт JSON и резервное копирование.
- **Обновления:** подписанные релизы из этого репозитория, установка только после подтверждения.

## Как обновляться

Начиная с **версии 3.6.1**, приложение поддерживает подписанные обновления. Откройте **«↻ Обновления»** или **«История и аудит → Обновления Windows-приложения»** и нажмите **«Проверить обновления»**. Если появится новая версия, ознакомьтесь с описанием и подтвердите установку.

Если у вас **3.6.0-preview.1** или более старая версия, загрузите новый установщик вручную один раз; предварительный выпуск не имел активного канала автообновлений.

## Данные пользователей

Библиотеки целей, координаты, настройки и история остаются на вашем компьютере. Кнопки **«↓ Копия данных»** и **«▤ Папка данных»** в верхней панели позволяют управлять резервными копиями. Перед переносом на другой компьютер экспортируйте JSON.

Приложение не передаёт пользовательские цели в GitHub. Проверка обновлений использует интернет только для получения метаданных и загрузки подписанного установщика.

## Исходники и сборка

Проект использует **Tauri 2, Rust, JavaScript и Vite**. Для самостоятельной сборки на Windows понадобятся Node.js, Rust, Microsoft C++ Build Tools и WebView2. После клонирования репозитория запустите `build-windows.bat` либо GitHub Actions **Build Windows installer**.

Подписание релизов и публикация доступны владельцу репозитория. Инструкция разработчика: **[UPDATES.md](UPDATES.md)**. Никогда не коммитьте приватный ключ Tauri и его пароль.

## Примечания

- Баллистические таблицы и проверенное расчётное ядро сохранены из версии 3.5 без изменений.
- VT и график траектории имеют указанные в программе ограничения приближённой модели.
- Программа является фанатским проектом и **не связана с Bohemia Interactive**.
- Лицензия на дальнейшее использование исходного кода отдельно не выбрана.

### Упрощённый интерфейс 3.6.3

Навигация сгруппирована по задачам, а в формах имеются пошаговые переходы, подсказки полей, явный статус свежести расчёта и проверка обязательного ввода. Поправки и дополнительные показатели можно раскрыть по запросу, не теряя историю и настройки. Клавиша F1 открывает руководство. Исходное баллистическое ядро не изменялось.

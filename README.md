# Arma Reforger Fire Control

**Arma Reforger Fire Control** — неофициальное офлайн-приложение для Windows (Tauri 2), основанное на проверенном игровом калькуляторе версии 3.5.

## Скачать

- **[Публичные сборки Windows / Releases](https://github.com/123312223a-pixel/Arma-Reforger-Fire-Control/releases/latest)** — установщики, включая подписанные версии с поддержкой обновлений.
- **[Состояние сборок / Actions](https://github.com/123312223a-pixel/Arma-Reforger-Fire-Control/actions/workflows/windows-build.yml)** — видно, проходит ли компиляция; результат также доступен как артефакт.
- Если список Releases пока пуст, первая сборка ещё не завершилась успешно. Не скачивайте неофициальные копии установщиков из сторонних источников.

> **Важно:** предварительная версия 3.6.0 не поддерживала обновления. Начиная с подписанного релиза 3.6.1 программа умеет искать и устанавливать подписанные обновления после подтверждения.

**[📖 Полное русскоязычное руководство](GUIDE_RU.md)** — пошаговая инструкция к калькулятору, карте, целям, батарее и обновлениям.

## Возможности

- Орудия M777, M252 и 2Б14 «Поднос».
- Подтверждённые шкалы азимута: 6400 тысячных для M777/M252, 6000 для 2Б14.
- Тактическая карта, компас, несколько орудий и библиотека именованных целей.
- Группы и категории целей, история, ручные поправки по сторонам света.
- Сравнение зарядов, таймер снарядов и сохранённые огневые задачи.
- Локальные данные, экспорт/импорт JSON и резервные копии AppLocalData.
- Подготовленный центр подписанных обновлений.

## Сборка из исходников

Понадобятся **Windows 10/11**, Node.js 22+, Rust 1.90+, Microsoft C++ Build Tools и WebView2.

1. Скачайте исходники: **Code → Download ZIP**.
2. Распакуйте проект и запустите `build-windows.bat`.
3. Установщик будет в `src-tauri/target/release/bundle/nsis/`.

Для автоматической сборки используйте workflow **Build Windows installer**.

## Как выпускать обновления

См. [UPDATES.md](UPDATES.md). Для подписанных обновлений нужно самостоятельно создать ключ Tauri и сохранить приватную часть **только у владельца репозитория**, затем настроить GitHub Actions Secrets. Публичный ключ можно разместить в GitHub Actions Variables.

## Данные и безопасность

История, координаты и сохранённые цели остаются на компьютере пользователя, если он сам не экспортирует и не передаст файлы. Секретные ключи подписи не входят в репозиторий. Предварительные релизы не подписаны сертификатом Windows и могут вызывать предупреждение SmartScreen.
